# Understand Advanced Log Analysis

## Overview

Advanced Log Analysis is the process of collecting, examining, correlating, and interpreting logs from multiple sources to identify security threats, investigate incidents, and understand attacker behaviour. Modern organisations generate large volumes of log data from endpoints, network devices, cloud platforms, applications, and security tools.

Effective log analysis allows threat hunters and SOC analysts to reconstruct attack timelines, identify anomalies, detect malicious activity, and uncover threats that may evade traditional security controls.

Advanced log analysis is a fundamental skill for threat hunting, incident response, digital forensics, and security monitoring.

---

# 1. Multi-Source Investigations

## What Are Multi-Source Investigations?

Multi-source investigations involve analysing data from multiple security systems and log sources to obtain a complete understanding of an event or incident.

Attackers rarely interact with only one system. Their activities often leave traces across endpoints, networks, identity systems, and cloud platforms.

By combining evidence from different sources, analysts can uncover hidden relationships and build a complete attack narrative.

---

## Common Log Sources

### Endpoint Logs

Provide visibility into:

- Process creation
- File activity
- Registry modifications
- User actions

**Examples:**

- Windows Event Logs
- EDR logs
- Sysmon logs

---

### Network Logs

Provide information about:

- Network connections
- Data transfers
- DNS requests
- Command-and-control communication

**Examples:**

- Firewall logs
- IDS/IPS logs
- Proxy logs
- NetFlow data

---

### Authentication Logs

Provide visibility into:

- User logins
- Failed login attempts
- Privilege usage
- Account activity

**Examples:**

- Active Directory logs
- Azure AD logs
- VPN authentication logs

---

### Application Logs

Provide information about:

- User interactions
- Transactions
- Errors
- Administrative actions

**Examples:**

- Web server logs
- Database logs
- Cloud application logs

---

### Security Logs

Generated by security solutions.

**Examples:**

- SIEM alerts
- Antivirus logs
- Threat intelligence platforms

---

## Investigation Example

### Observation

An employee account logs in from an unusual location.

### Investigation Process

1. Review authentication logs.
2. Check VPN logs.
3. Examine endpoint activity.
4. Analyse network connections.
5. Investigate data access records.

### Outcome

Correlating multiple sources may reveal an account compromise.

---

## Benefits

- Improved visibility
- Better context
- Faster investigations
- Increased detection accuracy
- Reduced false positives

# 2. Timeline Analysis

## What is Timeline Analysis?

Timeline analysis is the process of arranging events in chronological order to understand how an incident occurred.

It helps analysts reconstruct attacker activity and identify the sequence of actions performed during an attack.

---

## Why Timeline Analysis Matters

Attackers often perform multiple actions across different systems.

Examples include:

1. Initial compromise
2. Malware execution
3. Persistence establishment
4. Credential theft
5. Lateral movement
6. Data exfiltration

Understanding the order of events helps determine the scope and impact of an incident.

---

## Building a Timeline

### Step 1: Collect Logs

Gather events from:

- Endpoints
- Network devices
- Authentication systems
- Cloud services

---

### Step 2: Normalize Timestamps

Ensure all systems use a consistent time reference.

Examples:

- UTC
- Local time zones
- SIEM-normalised timestamps

---

### Step 3: Sequence Events

Arrange activities in chronological order.

---

### Example Timeline

```text
08:15 - Phishing email received
08:17 - Attachment opened
08:18 - PowerShell executed
08:20 - Malware establishes persistence
08:25 - Credentials collected
08:35 - Remote login from compromised account
08:45 - Sensitive files accessed
```

---

## Benefits

- Reconstructs attack paths
- Identifies attacker objectives
- Reveals missed detections
- Supports forensic investigations

# 3. Behavioural Analysis

## What is Behavioural Analysis?

Behavioural analysis focuses on understanding how users, systems, and attackers normally operate and identifying activities that deviate from expected behaviour.

Rather than relying solely on signatures or indicators, behavioural analysis examines patterns and actions.

---

## Behaviour-Based Detection

Focuses on activities such as:

- Unusual logins
- Privilege misuse
- Abnormal process execution
- Unexpected network traffic
- Suspicious user actions

---

## User Behaviour Analysis

### Normal Behaviour

```text
User logs in during business hours
from approved locations.
```

### Suspicious Behaviour

```text
User logs in at 3:00 AM from
an unfamiliar country.
```

---

## Endpoint Behaviour Analysis

Examples include:

- Unexpected PowerShell execution
- Process injection attempts
- Unusual service creation
- Suspicious scheduled tasks

---

## Network Behaviour Analysis

Examples include:

- Beaconing traffic
- Large data transfers
- DNS tunnelling activity
- Connections to suspicious destinations

---

## Benefits

- Detects unknown threats
- Identifies insider threats
- Uncovers stealthy attacks
- Supports proactive threat hunting

---

# 4. Anomaly Identification

## What is Anomaly Identification?

An anomaly is any activity that significantly differs from normal baseline behaviour.

Anomaly identification involves detecting unusual events that may indicate security incidents, misconfigurations, or malicious activity.

---

## Common Security Anomalies

### Authentication Anomalies

Examples:

- Multiple failed login attempts
- Impossible travel scenarios
- Logins from new locations
- Unusual account activity

---

### Endpoint Anomalies

Examples:

- Unexpected process execution
- New persistence mechanisms
- Rare administrative actions

---

### Network Anomalies

Examples:

- Communication with unknown hosts
- Unusual outbound traffic
- Unexpected protocol usage

---

### Data Access Anomalies

Examples:

- Large file downloads
- Access to sensitive information
- Abnormal database queries

---

## Example Investigation

### Observation

A workstation transfers significantly more data than usual.

### Analysis

- Review network logs.
- Identify destination systems.
- Investigate user activity.
- Determine whether data exfiltration occurred.

---

## Importance of Baselines

Effective anomaly detection requires understanding normal behaviour.

Baseline examples include:

- Standard login times
- Typical network traffic patterns
- Normal application usage
- Expected data access activity

---

## Benefits

- Early threat detection
- Identification of unknown attacks
- Improved security visibility
- Faster incident discovery

# 5. Event Correlation

## What is Event Correlation?

Event correlation is the process of connecting multiple related events from different sources to identify meaningful security incidents.

A single event may appear harmless, but multiple events occurring together may indicate an active attack.

---

## Why Event Correlation Matters

Attackers often generate multiple indicators during an attack lifecycle.

Without correlation, these individual events may appear unrelated.

---

## Example Events

### Event 1

```text
Multiple failed login attempts.
```

### Event 2

```text
Successful login from a new location.
```

### Event 3

```text
Privilege escalation detected.
```

### Event 4

```text
Large data transfer observed.
```

Individually, each event may seem insignificant.

Together, they may indicate account compromise and data exfiltration.

---

## Types of Correlation

### Temporal Correlation

Links events occurring within a specific timeframe.

### User-Based Correlation

Associates activities performed by a single user account.

### Host-Based Correlation

Connects events affecting a specific device.

### Network Correlation

Relates communication patterns across systems.

---

## SIEM Correlation

SIEM platforms use correlation rules to detect attack patterns automatically.

### Example Rule

```text
IF
Multiple failed logins
AND
Successful login occurs
AND
Privilege escalation follows

THEN
Generate high-severity alert
```

---

## Benefits

- Identifies complex attacks
- Improves threat detection
- Reduces alert fatigue
- Accelerates investigations
- Provides greater context

# Key Takeaways

- Advanced Log Analysis involves examining data from multiple security sources to identify threats and investigate incidents.
- Multi-source investigations provide a comprehensive view of attacker activity.
- Timeline analysis helps reconstruct the sequence of events during an attack.
- Behavioural analysis focuses on identifying suspicious actions rather than relying solely on indicators.
